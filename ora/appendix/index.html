ORA Appendix

Evaluation details, failure audit and provenance for ORA: Open Robot-Use Agents.

Protocol

RoboTwinAll 250 cases of the published C2R list, run directly on the randomized scenes with no clean-scene pass.
LIBERO-ProAll 800 Task and Swap cases, run with the current default harness.
LIBEROThe same evaluation run as LIBERO-Pro, all 400 cases, with the official base-suite instructions.
Model and budgetSelf-hosted DeepSeek-V4.1-Flash, low reasoning effort, task memory off. One scored outcome per case; at most 80 robot decisions, 200 model calls, 10,000 simulator steps and six hours. Five LIBERO and LIBERO-Pro cases had an infrastructure failure without a verdict and were rerun once as explicit -r1 replacements. The original attempts remain in the evidence; scores use their replacements.
TermsTask: a benchmark task. Case: a task with one seed from the published list. Episode: one attempt at a case. Round: one attempt within a session of several rounds on the same scene. Decision: one call that moves the robot.
Success checkThe model may call check_task, which returns the official success result for the current state without ending the episode. It never sees the check's code. We have not confirmed whether RPent's[1] agents have an equivalent query.
SuccessThe environment's own verdict, from a sealed, valid evaluation. A case without a valid outcome counts as a failure in the charts; the exact tables also give the rate over valid outcomes.
Versus RPentSame cases, different conditions: RGB-D images, geometry and grasp tools, ORA's task text (RPent's seed-specific wording for nine place_a2b cases), different action and time budgets. RPent's C2R protocol explores the clean scenes first and carries task memory to the randomized ones, with LingBot-VLA[2] as its primitive.
Harness versionRoboTwin results come from the earlier evaluation run. LIBERO and LIBERO-Pro come from a full rerun after the overhead-footprint change, with official base-suite instructions and restored observation rules. Several changes separate the rerun from the earlier tables, so it is not an ablation of overhead localization.
Leaderboard notesRPent lists GR00T-N1.7[3], π0.5[4] and StarVLA[5] without stating how they were run. RPent / GPT-5.5's 62.4% is the repository's update; the paper's Codex row reports 58.0%.

Table A1. Evaluation protocol for the results on the main page.

What changed in the full rerun

The LIBERO and LIBERO-Pro results come from a full rerun that replaced an earlier evaluation of the same cases. Paired case by case, the rerun turned 36 LIBERO failures into successes and 34 successes into failures (399 pairs, exact McNemar p = 0.91); on LIBERO-Pro the counts were 67 and 52 (796 pairs, p = 0.20). The small overall gains are therefore not a reliable improvement. Several harness changes went into the rerun, so it does not isolate the effect of any one of them.

RPent percentages and available denominators, including contributor corrections and the updated GPT-5.5 Long results, come from the pinned leaderboard page and its versioned result data, checked 2026-09-22. Cost

Cost covers the evaluation runs on the main page and the RoboDojo scan. Tokens are priced at DeepSeek's off-peak USD rates for DeepSeek-V4.1-Flash: $0.003, $0.15 and $0.60 per million cached input, uncached input and output tokens[17]. The self-hosted model does not report cache hits, so the cost script reconstructs them from request lengths: a call that contains the whole previous request and response counts that prefix as cached; any other call counts only the fixed prompt. The resulting hit rates are estimates, not measured cache hits. Simulator and GPU costs are excluded. Script: page/cost_usd.py.

Two controlled tests did not establish an improvement. With the RoboDojo motion-safety fixes, 12 of 102 rounds succeeded, against 11 of 102 without them (same code otherwise). A closed grasp skill on LIBERO succeeded in 35 of 60 paired states, against 41 of 60 without the skill (p = 0.18). Rerun variability is substantial: 15 of 30 failed LIBERO control cases succeeded on a plain rerun.

Still open

Success on LIBERO-Long and the two LIBERO-Pro long suites ranges from 52 to 64%, against 91 to 98% on Spatial and Object. On October 6, an earlier harness solved 18 of 126 rounds in a first scan of 42 two-arm RoboDojo tasks[18], completing 9 tasks at least once. In 64 of the 108 failed rounds the target was reasonable and the motion went wrong (27 of these judgements are low-confidence). The benchmark results compare complete systems in simulation with one language model; the component tests cover single changes under narrower conditions.
