Evaluates PR-agent, Devin, Claude Code, and Codex for code review. Existing agents solve only ~40% of tasks. Agent reviews often consider different aspects from human reviews — potential for human-agent collaboration
arxiv cs.SE, cs.AI
HEARTBEAT: Silent Memory Pollution in AI Agents
Critical vulnerability: background execution in personal AI agents can silently pollute memory via social misinformation. No prompt injection required — ordinary social content is sufficient. Misleading rates up to 61%, cross-session influence up to 76%
arxiv cs.CR, cs.AI

arxiv cs.SI, cs.AI
