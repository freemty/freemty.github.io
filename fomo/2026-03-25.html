Code Review Agent Benchmark (c-CRAB)
First dedicated benchmark for AI code review agents, evaluating PR-agent, Devin, Claude Code, and OpenAI Codex across functional correctness, style, security, and documentation tasks. Current best agents solve only ~40% of tasks, revealing significant headroom for improvement.

HEARTBEAT: Silent Memory Pollution in Claw AI Agents
Critical security vulnerability: background task execution can silently pollute agent long-term memory without any prompt injection. Social misinformation alone achieves a 61% misleading rate, meaning adversaries need no technical access to the system.

Studies how product listings adapt when AI agents become the buyers. Found Etsy listings gained machine-usable structured information following the ChatGPT release, suggesting markets self-optimize for AI consumption.
